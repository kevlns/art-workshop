# Vant 本地图片模型部署指南

## 目标

在用户指定目录部署或复用 ComfyUI 环境，接入 Qwen Image 2.1 Q4 图片生成及编辑。模型文件、固定版本与校验值读取同目录 JSON 契约，不猜测版本。根据实际系统、显卡、磁盘和网络制定命令；执行前明确任务范围。

## 检测

先读取 art environment guide，检测系统、GPU/显存、驱动、内存、磁盘、Git、Python、下载工具、端口以及已有环境。优先复用用户指定目录或 art 环境索引；不全盘扫描。没有 Git 可选择发行包下载，不重复执行失败命令。用户已有源码、虚拟环境和模型不直接覆盖。

## 执行

使用 Pi 基础工具与 Harness 受管进程执行。创建动态工作流，节点为检查环境、准备运行时、安装依赖、下载模型、配置服务、验证能力、登记环境。命令、错误和产物保存到任务记录。按实际反馈修正当前节点，成功节点不重复执行。

在目标目录创建独立 Python 环境，或复用经过检测的便携 Python。源码检出契约指定提交，依赖安装在该 Python 环境。按模型契约将文件下载到 ComfyUI/models 下，先写临时文件，校验 SHA256 后改为最终文件；保留有效文件并支持续传。网络失败时检查已有代理，仅在当前命令使用，不修改系统代理。不自行安装或更新全局 npm 工具。

低显存方案将文本编码器放在 CPU，服务使用 --disable-dynamic-vram --lowvram --disable-auto-launch。不要承诺显存一定充足。服务仅监听回环地址。端口占用时核对服务身份，不能将另一套环境误登记为当前目录。

## 验收

分别记录文件校验、服务连通、节点/工作流能力和真实采样。使用 art environment verify 对当前目录和端口验收；验收失败按原始错误修正。真实生成和编辑通过 art 的计划及任务机制执行，保存原 taskId，不重复提交未知请求。只有实际图像及完成回执能够证明采样成功。

使用 art environment register 重新核验并登记已通过能力检查的环境。能力验收不等于采样验证；缺少真实采样时明确展示。登记完成再更新 Vant 的本地环境设置。

## 取消与恢复

用户普通插话不终止工作流。工作流停止时等待本任务进程实际退出，保留已校验模型、已有用户文件与执行证据。只停止能够核验身份的本任务服务，不能杀全部 Python 或关闭用户原有服务。恢复时先读任务记录、检查原进程与文件；未知副作用先核实，不重跑整个安装。关闭部署窗口不取消任务。
