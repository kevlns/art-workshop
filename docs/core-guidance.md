# 核心冻结指导规则

权威规则：rules/core-guidance.json。模型分析、配置校验和冻结记录共用这一份。

1. 语言精炼：每条规则表达一个可执行要求，避免重复和修辞。
2. 用词准确：统一术语，明确强度、范围与条件，不混用不同渲染机制。
3. 前后一致：报告、推荐、冻结、正向和负向提示词、验收要求保持一致。
4. 职责分明：核心定义视觉规律；资产定义背景和构图许可；需求定义主体、数量、动作与关系；执行定义模型和尺寸；编辑定义修改与保留。
5. 单一来源：一个事实只有一个权威字段，提示词从结构化配置生成。
6. 作用域明确：规则明确作用对象，题材适配不能覆盖全局渲染或冻结单张内容。
7. 观察与建议分开：观察保留证据和置信度，建议进入推荐配置，不确定性显式列出。
8. 跨内容复用：不把参考图偶然的颜色、数量、背景和布局冻结为普遍要求。
9. 冻结可追溯：保留报告、规则、身份和哈希，冻结后不原地修改，任务明确选择基础核心。

校验覆盖结构、枚举、已知语义组合、精炼度与常见职责越界，不能穷尽自然语言全部语义矛盾，冻结前仍需审阅。未解决的 conflicts 或 uncertainties 会阻止冻结。
