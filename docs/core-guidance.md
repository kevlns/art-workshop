# Vant 风格核心职责与问题决策

## 定位

风格核心职责与问题决策，适用于当前随包实现。

## 前置条件

先按包的环境要求准备工程与工具，使用实际配置和命令帮助核对目标。

## 操作流程

风格定义如何绘制。主体轮廓、比例、部件、姿态、身份色、物理材质、光源、构图与资产尺寸由任务决定。

### 最终规范

报告和核心使用 schemaVersion=3，项目与对象存储版本仍为2。recommendation 只含 rules：每条具有稳定 id、scope、strength、instruction、when；avoid 可填写 negative 字符串数组。

- scope：medium、shading、outline、highlights、brushwork、detail、palette。
- strength：required 必须遵守、default 默认倾向、avoid 必须避免。“默认少用”仍使用 default，不升级为禁止。
- instruction：300字以内的独立、准确、精炼绘制要求；不能出现本轮、上一版、修改经过等迭代描述。
- when：适用条件，无条件时为空。局部例外与默认倾向可以共存，不强制精确色值、线宽或色阶。

生成提示按主题组织，保留条件与强度。正向表达绘制语言，负向排除抽象的渲染、笔触或语言混杂等特征；负向不能变成主体、部件、身份色、具体材质和纹理的黑名单。不得从参考图中未出现的内容推断禁止条件。

negative 为可选的被排除特征列表，不加“避免、不要、禁止、no、without”等否定前缀。instruction 为同一规则的阅读说明；条件与例外写入 when。仅无条件 avoid 且明确填写 negative 时编译进独立负向段；其余文字约束及条件排除保留在正向规则段，不猜测条件、不机械转换。default 不升级为负向禁止；正向与负向按路由去重，完整已保存配置保留阅读说明。

模型支持独立 negative_prompt 时直接发送；不支持时适配器将负向约束明确并入正向排除段，使用合并后的提示词长度限制，不默默丢弃或截断。ComfyUI 将其绑定到 negativePrompt 输入，缺少绑定则明确报错。界面预案显示适配后实际请求，条件排除和全局负向分别说明。最终核心只使用规则，不把聊天记录、问题解释或证据局限混入生成规范。

### 报告与取舍

summary 概述当前方案，observations 保存分类证据，notes 保存不影响执行的提醒。issues 只表达真正需要用户选择的矛盾，每项有稳定 id、question、reopenReason 与2至5个 options。选项含 id、label、remove 规则ID和 upsert 规则。

style resolve 校验 revision、报告来源和选项，记录 issueId、问题指纹、optionId、用户依据和时间，reviewHistory 记录历次选择。报告建议中的矛盾按用户实际选择处理；不要清空问题或伪造分析证据。用户直接编辑的 config.rules 通过 style update 保存，不要求报告 ready 或再次采用。

风格规则可以随时增删修改并保存，包括历史状态为 frozen 的风格。style update 接收完整 config，保存有效 rules 后同步当前 core.json，旧核心按 coreHash 存入 core-history；历史运行中的快照保持原样，未执行预案须重新编译。分析配置或参考变化保留原报告并标记需复核，但不强制用户重新分析才能保存规则。style revise 作为兼容修订入口记录用户依据，不自动调用模型。

独立派生仍可保留结构化规则与参考，用于创建不同方向的风格；不再作为修改的前提。旧职责版本保留原始证据，通过显式迁移整理，不能自动解释为当前规则。内部 status=frozen 兼容表示已有可执行核心，界面不应据此禁用编辑。

需要分析复核时，复核提供上一版方案和决定；同一证据、问题与选项不变时保留决定，新证据或明确重新打开理由要求重新确认。逐图观察按内容和分类契约缓存，未改变的图不重复请求。

### 用样张验证规则并定版

保存规则后用 style sample-job 创建仅规则打样任务；按普通生成流程配置模型和执行，不自动发起生图。使用简单且不同的主体检查这套规则组合的实际表现，用户不满意时直接修改保存规则并重新打样。用户选定后通过 style sample-select 完成样张定版并保存独立运行时参考，来源和当前规则哈希随样张记录；样张定版不调用 candidate finalize，不导出到 VantArtForge。

后续任务可以选择 approved 运行时参考或 text-only 仅规则。原始分主题图不会因存在于风格中而直接传给生成模型。运行时参考仅表达绘制语言，主体、结构、身份色与构图由当前任务决定。规则变化后的旧样张显示过期；已有样张全部过期时不能用于 approved，混合新旧样张只采用当前匹配项。模型不支持图片参考时明确报错，不静默改变模式。规则保存本身不意味着已经通过实际视觉验证。



候选图片使用“样张定版 / 取消样张定版”开关，对应兼容 API style sample-select / sample-remove；这只维护当前风格的运行时参考，不执行资产定版或导出。定版图片在“风格配置 → 运行时参考”显示，按图片内容哈希去重，重复图片不会新增一份。任务的 approved/text-only 决定是否使用运行时参考，不为每张参考另设启用开关。
