## 原试验范围

原记录涉及细胞题材技能图标、单位概念图，以 ATP 工厂原画为风格参照，尝试赛璐璐处理与无框图案。原记录写明使用 qwen-image-2.1-pro、迭代 8 轮、出图 25 张、累计约 6.3 元；这些是当时记录，不是本轮重新核对的账单，也不用于估算当前任务费用。

## 保留的观察与当前设计归属

| 历史观察 | 当时采取的办法 | 当前结构中的位置 |
|---|---|---|
| 将风格参考作为编辑底图时，输出复刻参考主体，需求主体丢失 | 分析参考风格后走文生图 | style refs 用于分析；edit source 是真正底图 |
| 多张候选构图相似 | 调整 seed 进行对照 | item/variant seed；不将相邻 seed 相似推广为必然规律 |
| 只有效果词时主体不可读 | 明确主体、动作和效果 | entities/effects/relations/mustRead |
| 出现未要求的边框或环形外壳 | 澄清正向构图及表面作用范围 | profile 资产约束、core.domains、item 内容 |
| 全局冷色规则覆盖红细胞身份色 | 保留主体色，统一渲染而非同色 | item.color 和 core.color 的职责分离 |
| 枚举多种细胞被理解为画面元素清单 | 从全局风格删除具体内容枚举 | 核心只保留可复用规则，实体清单属于任务 |
| 风格变更影响其他图片 | 固定可控参数做少量 A/B | 新核心与新计划、compare、逐图人工审查 |

这些观察来自特定版本和样本。负向词的构图作用、相邻 seed 的关系、参考图尺寸限制等不能据此写成适用于所有模型的硬规则。
