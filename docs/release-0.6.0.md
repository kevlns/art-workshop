# art-workshop 0.6.0

本版本提供图片与视频独立通道及可导入的视频 SDK，包含可编辑风格规则、样张任务、样张定版引用、原始会话出图、分析证据与有界报告修复。宿主通过机器清单发现能力，不能仅凭包版本推断命令存在。

风格分析是可选复核；已整理的规则可直接创建样张任务。样张只使用当前规则，原始分析参考不会自动进入生成输入；用户定版后的样张才可作为后续运行参考。

Qwen 本地部署支持 Python >=3.11 且 <3.14，继续优先为新环境准备 Python 3.12。原 `<3.13` 上界与指南固定的 ComfyUI 提交不一致：该提交的 README 明确支持 Python 3.13，Windows 便携版使用 Python 3.13 / CUDA 13.0。已有 3.13 环境无需因此替换。版本通过后仍需检查模型、节点、服务能力及进程归属。

发布验证包括完整测试、命令文档校验、包文件与能力清单检查，以及隔离安装中的 CLI、视频导出和原操作回执。真实模型生成、GPU 输出效果和外部视频服务并不由这些测试自动证明。
