# 绑定、修形与表演

## 绑定与蒙皮

先在设置姿势拼回原画。根骨控制整体位移，身体和头承担主要姿态，手腕、耳尖、尾焰等按独立运动需求挂在合适的父骨下。把枢轴放在实际弯折或旋转的位置，核对 slot 的绘制顺序。硬饰品可用普通附件跟骨；需要弯折的软轮廓再做网格，在弯折和轮廓变化处增加顶点。

蒙皮从主要骨骼的影响开始，沿关节逐步过渡，检查权重归一化。共享接缝两侧的顶点跟随要一致。分别转动父骨、子骨并测试组合极限姿，检查塌陷、滑动和穿帮。若旋转时纹理大幅拉长，先判断缺的是另一个手形、另一视角还是遮挡底图，再决定是否加骨或加点。[Spine 权重工具](https://esotericsoftware.com/spine-weights)

## 对照修形

用目标运行时渲染设置姿势或约定帧，在与基准图相同的坐标窗口比较。固定根位置、缩放和相机，做并排图或半透明叠图。先看剪影和比例，再看眼角、下巴、袖口、指尖等定位点。设置姿势就偏，查图层偏移、枢轴和设置姿势；仅某个动作偏，查该帧的关键帧、权重、附件切换和混合。

Vanter 将设计板大正面与 Unity 首帧放在同一窗口对照。修脸时以已认可的生气动作第 12 帧脸颊和下巴为基准，约束表情变形在轮廓内，再回看待机、眨眼与生气。这比让每个表情各自生成一张完整头像更容易保持角色一致。

## 动作与转场

从观众应读懂的意图选关键姿态。先让起势、最有辨识度的姿势和收势在实际大小下可读，再调重心、停顿、加减速和次级摆动。待机的呼吸、浮动和眨眼可以有不同节奏；一次性动作要明确接续哪个状态，退场要标明完成点。以正常速度检查情绪，再慢放排查穿插和跳帧。

除了单播，还要从正在运行的上一个动作切入，再接回下一状态。循环同时检查首尾姿势和速度；切换附件、层序、透明度的帧要在混合中实际播放。Vanter 的叉腰先收腕到胸前再落拳到腰，耳尖和尾焰在主体停住后回弹。验收片是「待机 → 叉腰 → 待机」，两个方向的混合时间可分别调整。

## 命名与索引

同一意图的多种演法归入同一类别。例如轻挥手和大幅挥手可命名为 `wave_001`、`wave_002`，语义不同的告别可另建 `wave_goodbye_001`。类别分段用小写英文字母开头，可带数字。编号范围为 `001` 至 `999`，新变体沿用该类下一个可用的新编号。删减允许留下空号，保留动作不重新编号。

导出 `animations.json`，把每个类别映射到按编号升序排列的非空动作名数组，例如 `{"wave":["wave_001","wave_002"],"wave_goodbye":["wave_goodbye_001"]}`。每个交付动作在自己的类别中出现一次，骨架与索引的名称集合完全一致。随机选择在同一类别内进行。

导出后运行 `node <技能目录>/scripts/check-variants.mjs <骨架.json> <animations.json>`。二进制交付使用同一次导出的 JSON 副本核对名称，再用目标播放器加载最终 SKEL 核对动作列表。接手已有资产时保留已公布的调用名；需要规范化改名时，同步修改源工程、索引、默认动作、转场及调用方，再重导验收。

## 运行时预览

在 Vant 中用 Spine 浮窗播放正在编辑的骨架，切换动作看起止姿势与循环接缝；复杂对照进 Spine 工坊。按最终显示尺寸看一次，固定根位置、缩放与背景，避免自动裁切造成假抖动。只有涉及目标引擎特有的材质或混合行为时，再到对应引擎复核。

需要留存问题帧时导出 PNG。采帧用相同画布、真实播放时长，循环末尾避免重复首帧。渐变或透明边的质量以运行时画面为准。
