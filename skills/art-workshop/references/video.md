# 视频通道

先用 `art-workshop video describe --workspace <工程绝对根目录>` 或 `v-cli agent describe art --json` 取得当前能力与输入契约。视频使用独立的模型、工作流和任务，不复用图片计划或图片全局配置。

请求 JSON 放在工程内文件，通过 `--input` 传入。写操作使用稳定的原操作身份；运行还需要业务契约中的 `requestId`。读取、规划和保存配置不启动生成。只有用户意图明确包含执行时，才运行对应原生工具能力；宿主的权限及审批仍然适用。

- 先读任务、操作、设置和 revision，再准备更新或运行。
- 剧本规划、尾帧采纳、成片合成和精修使用各自明确动作，不用提示词替代前后依赖校验。
- 结果未知时查询原操作、原 `requestId / runId / upstreamId`；不更换 ID、入口或目标重投。
- 取消只处理原排队身份。服务不支持安全的单任务停止时保留原运行，不中断其他共享任务。
- 当前缺模型、FFmpeg、节点或服务时如实说明；保存成功不表示运行环境或生成已验收。

视频模型及工作流配置保存在工程 `.vant/config/video.json`，任务、素材与成片保存在 `.vant/video`。与图片通道分别读取各自的配置和 revision，不迁移或覆盖已有图片对象。
