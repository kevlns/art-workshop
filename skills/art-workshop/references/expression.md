# 美术表达规范

讨论、风格分析、报告和任务配置中的美术表达采用以下默认顺序；简单修改可以合并步骤，没有专业歧义或核实需要时跳过检索，不将步骤变成固定工作流或逐项确认关卡。只优化前置表述，不为验证措辞启动分析、生图或出图评审。

## 适度整理与补充

目标是让美术同学更容易理解和执行，不要求逐字改写或零扩写。可以调整次序、合并重复、使用专业表达，也可以补充与原意一致的自然衔接和合理执行细节；是否合适主要看有没有改变用户想要的结果。

- 保持原有方向、程度、条件和例外。“少用”不宜变成全面禁止，“可以有”不宜变成必须出现；局部调整也不宜扩大到整幅或所有资产。这些是实质性变化，与普通措辞补充区别处理。
- 看图分析可以提炼有图像依据的媒介观感、线条、笔触、明暗和色彩关系，并适度转化为可用的风格描述。对推测性的工艺、媒介来源或通用性判断用恰当的倾向表达，不因单张图没有某种表现就认为以后必须禁止。
- Getty 帮助核实概念，不代替美术判断。结合上下文解释即可，不必将定义未提到的内容判为不允许，也不为术语分类强行拆开可以并存的要求。
- 少量、顺理成章的补充可直接融入，无需逐项标建议或请求确认。明显改变画面方向、增加硬性限制或存在多种差异较大的解释时，再简短提出建议或请用户选择，其余明确内容继续处理。

回填前快速看一遍有没有偏离原意、遗漏保留项或无意升级强度；必要时局部修正即可。不要为每个新增形容词建立证明或确认关卡，也不因细节未穷尽而反复追问。原配置与工具默认值继续沿用，避免把本轮讨论扩大成全面重写。

## 整理与保存

1. 理解意图与主题归类：先明确对象、属性、调整方向、程度、条件及保留要求。区分跨主体复用的绘制语言与当前任务的主体、结构、材质、光照、构图和交付约束，按相关主题组织，不强制填满分类，不为分类补造需求。
2. 初步整理与语义去重：统一同一对象的称呼，合并对象、含义和适用条件均一致的重复要求；程度、条件或对象不同的内容分别保留。含义不确定时保留原表达和上下文，暂不强行合并或替换，避免先精简掉消歧依据。
3. 按需专业对齐：发现专业概念歧义或需要核实时，先从中文原意、作用对象及条件中提炼简短的英文专业检索词，再通过实际可用的 Getty 或项目表达库召回概念。不是逐字翻译整段描述，也不将英译当成已确认结论；有多个合理含义时在同一批次查询，不在结果不理想后反复换词。原始中文及约束保留在 context，候选返回后结合类别、概念说明和原始上下文判断，不只按首条或分数采用。Vant 使用 art_getty 结构化入口，不拼 Python、脚本或请求文件路径。缓存由查询工具管理，仅复用完整检索词及影响结果的全部参数完全一致的请求，不做语义近似缓存；不伪造概念 ID、结果或工具能力。无需引入 OpenRefine 运行依赖。
4. 精炼表述与整体校验：采用明确且符合原意的概念后，删去空泛修饰与重复说明，形成独立完整的描述；保留对象、程度、条件、例外和 required/default/avoid 的原有强度，不设机械字数限制。核对前后术语及要求一致，未遗漏约束、增加未经支持的含义或混淆风格与任务职责。发现问题做局部修正，不自动回到起点反复检索或改写。
5. 回填并结束：明确且校验通过的修改在用户当前编辑授权内自动回填，无需逐项确认；读取当前对象及 revision，保留未修改配置，按工具契约保存并核实返回结果。筛选后仍有多个合理解释时，按匹配程度排序，通过宿主现有决策入口展示候选含义、匹配依据、差异和拟回填内容，标明推荐项并允许保留原表达或自行修改；未决字段保留原值，其余明确修改继续处理。无匹配、查询能力不可用、服务失败或语义校验未通过时，保留受影响的原表达，简短说明局限并结束本次对齐，不强行绑定概念或自行重试循环。配置保存失败须如实报告，不声称已回填；技术契约校验仍按原规则执行。

Getty 调用前按需读取 `references/getty.md`。Vant 的 art_getty 由宿主定位受管包中的 `scripts/getty.py` 和共享 Python，通过标准输入输出交换 JSON；模型不用寻找或创建脚本。其他宿主只使用其明确提供的执行入口与解释器，缺少能力时说明失败，不猜路径、搜索系统 Python 或改用临时脚本。适配器负责 AAT 查询、详情、精确缓存和错误分类，模型负责词语提炼和语义判断。上游 serviceScore 只是检索排序分数，serviceMatch 不等于语义通过；失败即保留原文并结束当前检索，不用网页查询冒充已完成 Getty 核实。


每轮对齐只做一次有界整理与查询批次；查询候选可含原词和有依据的候选译名，使用不同 query ID 保留来源。一次局部修正后仍有歧义就交决策卡或保留原文并结束，不为提高检索分数反复换词。用户选择候选后只处理该未决项，不重新启动整套流程。
