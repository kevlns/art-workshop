# 会话美术管线

使用 art_conversation describe 获取当前输入契约。只讨论时自然答复，不执行生成。

一次 generate 或 edit 请求绑定 requestId；相同 requestId 重复调用只返回原运行，不重发。已有产物通过 attachmentId 指定；编辑必须明确底图，引用可以分别指定主体、配色、构图、风格等用途，不把全部会话图片自动作为参考。读取像素后再解释，不能看图时使用已配置的视觉分析能力或说明限制。

生成和编辑使用 prompt、引用及已有执行设置，不创建业务 job 或冻结风格。未指定主题规格时使用会话默认值，不能伪造资产要求。只补问实际影响行动的歧义；已授权的普通生成不重复要求确认，宿主执行策略仍生效。

generate/edit 返回 runId 后只查询该运行；status 每次只读取一次状态，不进行模型轮询循环。完成后由宿主发布真实图片附件，失败如实说明，unknown 只查询或恢复原运行。等待达到上限时结束本轮并保留句柄；不自动重跑成功项，不换模型重投，不将取消变成新请求。

用户对结果提出新修改时，使用明确底图提交新一轮，requestId 仍由宿主绑定该条用户消息。用户要求转为项目任务时调用 promote，保留原图片及来源，不重新生图、不自动定版。
